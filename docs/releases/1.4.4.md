# MFG Unlock 1.4.4 - DLSS-G 310.9.16 Hotfix

This hotfix adds compatibility with **DLSS-G 310.9.16** and **Streamline 2.14.16**.

### Compatibility fixes

- **Dynamic MFG recognizes the new runtime versions.** The menu and version checks now accept 310.9.16 and 2.14.16. The previously supported 310.9.1 and 2.14.1 versions remain accepted.
- **Updated quality patch for the new provider.** The validated warp blend path now handles the changed blend-kernel parameter layout and output registers in 310.9.16, with its own exact kernel fingerprint.
- **Runtime safeguards retained.** Loaded-module verification, the provider's Dynamic MFG capability check, D3D12 requirements and unknown-kernel fallback remain in place. Star Wars Outlaws keeps its fixed/game-controlled compatibility path.

This hotfix builds on 1.4.3 and retains its continuous border stability, Local Stable geometry and V2 Compatibility inpaint.

### Validation

All **32 automated tests passed**. Offline patch/restore checks passed on both 310.9.1 and 310.9.16. The complete release blend shader passed NVIDIA driver JIT compilation for both providers at **48 registers**.

**In-game validation on the new runtime is still pending.** These checks do not establish a performance improvement or universal game compatibility.

### Installation

Close the game, replace the previous addon with **renodx-mfgunlock.addon64**, keep only one MFG Unlock addon installed, and restart. Your existing configuration can be retained; no INI reset is required.

When updating NVIDIA runtime DLLs, use a complete matching Streamline package and verify the loaded versions in the addon panel. This download contains the addon only.
