## Local Stability & CPU Overhead

This update builds on the local, low-overhead path introduced in 1.4.1. It improves border and diagonal-support continuity, corrects input-state/reset handling, and removes redundant CPU work. Inpaint remains V2 Compatibility; confidence history and temporal launch interception remain disabled.

### Image stability

- **Smoother subpixel border transitions.** The transition between symmetric and motion-directional border treatment is now gradual over 0.5–1.5 pixels of movement instead of switching abruptly at 0.5 pixels. This targets confidence oscillation during slow camera movement near screen edges.
- **Paired diagonal support.** Two independently validated diagonal neighbors can now contribute to the two-support geometry consensus. Both contributions remain limited by the weaker neighbor's coherence and the existing ambiguity/orientation ramps.
- Structural hard rejects and the native warp-weight anchor are preserved. No additional texture reads or confidence-history buffers are introduced.

### Input-state and reset fixes

- Clearing optional HUD-less/UI tags no longer creates a false input-path transition or an unnecessary reset.
- Input-path state now follows the resources actually forwarded, including contention fallbacks, and is committed only after a successful API call.
- Rejected tag/options calls no longer certify an input-path or options change.
- The scalar diagonal reference now matches the PTX's Euclidean movement-length calculation.

### CPU overhead

- Repeated, unchanged DLSS-G options use a versioned atomic snapshot, avoiding the viewport writer lock and redundant state updates.
- Inactive native Present/latency-monitor paths skip controller synchronization when no pending restore, refresh, or owned automatic cap requires it.
- Active controls and pending transitions retain their existing synchronization and safety checks. No automatic Reflex or pacing override is introduced.

### Output FPS Cap

- Output FPS Cap can activate in **Game controlled** when an accepted FG request is supported by a fresh driver report of an active 2x–6x multiplier.
- Driver status is sampled at most twice per second while an explicit cap is configured.
- Diagnostics now explicitly report when **FG-safe Off** or active **DXGI Waitable** prevents guaranteeing the native-sleep-based cap. No additional limiter is added on those paths.

### Preserved behavior

- InputMvecProcessing and the game's supplied motion vectors are unchanged.
- Local V3 geometry, V2 Compatibility inpaint, and provider-native scatter remain in use.
- No temporal confidence-history backend, CUDA/NVAPI launch interception, GPU self-tests, or history synchronization barriers are enabled.
- V3 patches still require the exactly validated **DLSS-G 310.9.0 or 310.9.1** providers. Unknown providers receive no V3 patches.

### Validation and limitations

All **29 laboratory tests passed**, followed by **26 tests on the isolated release source** (which excludes the unrelated observer and warp-preset tests). Offline assembly/JIT validation reports **48 warp registers** and **40 geometry registers**, with zero stack, spills, or local memory. Resource-access instruction streams were checked against the baseline: no additional texture reads were introduced.

The candidate has been tested by the maintainer in several games. These checks are not a quantified cross-game GPU, Reflex, or end-to-end latency benchmark. The changes are intended to improve local stability and reduce CPU overhead; they do not guarantee universally improved mouse response or elimination of ghosting/flicker. Missing vegetation/hair deformation motion vectors are not repaired by this update.

### Installation

Close the game, replace the previous `renodx-mfgunlock.addon64`, keep only one MFG Unlock addon installed, and restart. Keep your existing configuration; no INI reset is needed.

The border and diagonal changes require the V3 profile with **Motion-directional border taper** and **Motion-oriented diagonal geometry** enabled. CPU/state fixes apply without enabling a ReShade shader. No full NVIDIA DLL/provider package is included; existing credits and the MIT license are preserved.
