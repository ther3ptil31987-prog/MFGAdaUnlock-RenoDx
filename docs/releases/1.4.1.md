## Local Low-Overhead Update

This update removes the experimental confidence-history backend and returns inpaint to **V2 Compatibility**, while retaining the established local Adaptive Quality V3 improvements.

### Why was Inpaint V3 removed?

Recent testing did not show a consistent visual benefit sufficient to justify its additional complexity. The confidence-history backend also failed activation checks in reported sessions, so installing a Temporal cubin did not guarantee temporal stabilization was actually running. This release returns to V2 Compatibility and removes the experimental history backend, prioritizing reliability and lower processing overhead while preserving the established local V3 quality improvements.

### What changed

- **Inpaint V3 removed from the active path.** Inpaint now uses V2 Compatibility, with the existing V1/native safety fallbacks.
- **Geometry uses the dedicated V3.1 Local Stable cubin**, without temporal confidence history. Its local silhouette and directional-support improvements remain enabled under the V3 profile.
- **No CUDA/NVAPI temporal launch interception**, history allocations, GPU self-tests, private phase modules or backend synchronization barriers.
- Saved temporal geometry and inpaint settings are ignored in this build without rewriting your configuration. Temporal controls are replaced with a clear explanation in the UI.
- Diagnostics explicitly show that the confidence-history backend is disabled. A temporal hook fast path is no longer needed because these launch hooks are not installed.

### What stays the same

- V3 luminance/chroma validation, directional borders, local oriented geometry and provider-native scatter.
- Existing MFG multiplier controls and non-temporal compatibility paths.
- Reflex, FPS caps and pacing settings; no automatic pacing override is introduced.
- Exact V3 provider validation for **DLSS-G 310.9.0 and 310.9.1**. Unknown providers receive no V3 patches.

### Validation and limitations

All **26 automated tests passed**. The compiled addon passed an audit for the absence of CUDA temporal-hook lookup strings and the NVAPI temporal self-test.

The goal is to remove the temporal backend's processing and synchronization overhead. This release does **not** claim a measured end-to-end latency reduction, universally improved mouse response, or completed cross-game visual/performance validation. The older Witcher 3 vegetation/hair cadence issue is not addressed here.

### Installation

Close the game, replace the previous `renodx-mfgunlock.addon64`, keep only one MFG Unlock addon installed, and restart. Keep your existing INI; no configuration reset is needed.

No complete NVIDIA DLL/provider package is included. Existing credits and the MIT license are preserved; see the repository README.
